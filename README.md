# پلنیفای (Planify) 📋
### سامانه مدیریت وظایف تیمی مقیاس‌پذیر با استفاده از طراحی دامنه‌محور (DDD)

## 📖 درباره پروژه
پلنیفای یک سیستم بک‌اند قدرتمند برای مدیریت وظایف تیمی است. هدف اصلی از ساخت این پروژه، فراتر رفتن از عملیات‌های ساده CRUD و پیاده‌سازی یک **مدل دامنه غنی (Rich Domain Model)** برای کپسوله‌سازی منطق‌های پیچیده کسب‌وکار در لایه دامنه بود تا سیستم در مقیاس‌های بزرگ همچنان قابل نگهداری باقی بماند.

## 🏗️ معماری و تصمیمات طراحی
این پروژه به دقت از اصول **معماری تمیز (Clean Architecture)** و **طراحی دامنه‌محور (DDD)** پیروی می‌کند.

*   **طراحی دامنه‌محور (DDD):** قوانین کسب‌وکار به شدت در لایه دامنه ایزوله شده‌اند. موجودیت‌ها دارای رفتار (Behavior) هستند و صرفاً مدل‌های داده (Anemic Models) نیستند.
*   **احراز هویت و کنترل دسترسی:** استفاده از فریم‌ورک Identity در ASP.NET Core ترکیب شده با یک سیستم مدیریت نقش‌ها و سطوح دسترسی (RBAC) پویا و مقیاس‌پذیر.
*   **طراحی API (RESTful):** توسعه و پیاده‌سازی استاندارد APIهای RESTful با استفاده از ASP.NET Core Web API برای تعامل یکپارچه با کلاینت‌ها و فرانت‌اند.
*   **ارتباطات داخلی (gRPC):** استفاده از gRPC برای ارتباطات درون‌سیستمی و سرویس‌های داخلی، به منظور دستیابی به پرفورمنس بالاتر، تاخیر کمتر (Low Latency) و تایپ‌سیفتی دقیق از طریق Protocol Buffers.
*   **دیتابیس:** استفاده از Entity Framework Core به عنوان ORM، با رعایت الگوی Repository برای انتزاع دسترسی به داده‌ها.

## 🚀 تکنولوژی‌ها
*   **فریم‌ورک:** .NET (ASP.NET Core)
*   **زبان:** C#
*   **معماری:** Clean Architecture, DDD, CQRS
*   **احراز هویت:** ASP.NET Core Identity, JWT
*   **ارتباطات:** RESTful APIs, gRPC
*   **ORM:** Entity Framework Core

## 🧩 ویژگی‌های کلیدی
*   سیستم کنترل دسترسی مبتنی بر نقش (Role-based) و سطح دسترسی (Permission-based).
*   ایجاد، تخصیص و تغییر وضعیت وظایف با رعایت کامل قوانین دامنه.
*   ارائه APIهای RESTful کامل و استاندارد برای مصرف کلاینت‌ها.
*   مستندسازی کامل APIها با استفاده از Swagger.
